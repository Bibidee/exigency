# UI Direction

The visual brief used ODDLOCKK only as a quality reference: deliberate typography, strong contrast, layered depth, motion restraint and a distinctive product identity.

EXIGENT deliberately does **not** copy its palette, route structure, component names, wager language, ledger metaphor or page layouts.

EXIGENT's own visual language is an **emergency control room**:

- near-black graphite base;
- cold cyan for verified control state;
- amber for pending/time-sensitive authority;
- red only for destructive/rejected state;
- gridded technical background;
- compact mono data fields;
- large editorial landing typography;
- left application rail on desktop and compact top rail on mobile;
- capability/incident records presented as authority objects rather than dashboard cards.

The goal is functional beauty: the UI should make finality, source state, exact authority and failure conditions easier to understand.
